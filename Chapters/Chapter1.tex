\section{Introduction to the Core Concepts}

The contents of this chapter establish the theoretical and mathematical foundations of modern deep learning, largely based on the introductory modules of the course~\cite{galasso2025nn,galasso2025training}.

\begin{keywordbox}
\begin{itemize}[nosep, leftmargin=*]
\item According to Arthur Samuel~\cite{samuel1959some}, \textbf{Machine Learning} is the field of study that gives computers the ability to learn without being explicitly programmed. 

\item Tom Mitchell (1998) defined the well-posed learning problem: a computer program is said to learn from experience $E$ with respect to some task $T$ and some performance measure $P$, if its performance on $T$, as measured by $P$, improves with experience $E$.
\end{itemize}
\end{keywordbox}

Machine learning is heavily applied in \textbf{Computer Vision}, which can be viewed from three main perspectives: as a science (exploring the computational model of human perception), as engineering (building systems that perceive the world), and through its applications.

\begin{examplebox}
Some typical \textbf{Computer Vision Applications} include:
\begin{itemize}[nosep, leftmargin=*]
    \item \textbf{Medical imaging}: Supporting medical diagnosis and visualization.
    \item \textbf{Surveillance}: Tracking people in airports or train stations.
    \item \textbf{Autonomous driving}: Lane-keeping and pre-crash intervention.
\end{itemize}
\end{examplebox}

\section{Parametric Models and Optimization Foundations}

In \textbf{image classification}, the input is an image and the output is one label from a fixed set (for example \textit{cat}, \textit{dog}, \textit{truck}). Most models in this course are \textbf{parametric}: they take an input $x$ and use a set of learnable weights $W$ and biases $b$ to produce a prediction. The simplest case is the linear score
\[ z = f(x,W) = Wx + b, \]
which is exactly the linear classifier shown in the lecture slides. For a $32 \times 32 \times 3$ image, $x$ is a vector of $3072$ numbers; if we have $10$ classes, $W$ has shape $10 \times 3072$ and $z$ is a vector of $10$ class scores.

What unifies these models is the way they are trained. We define a loss $L$ that measures the error of the predictions, and we adjust the weights with \textbf{gradient descent}:
\[ W^{t+1} = W^t - \alpha \nabla_W L, \]
where $\alpha$ is the learning rate. The gradient points in the direction in which the loss grows fastest, so we move in the opposite direction.

By changing the activation applied to the linear score and the corresponding loss, we obtain the classical models: Linear Regression, Logistic Regression, and the Softmax Classifier.

\subsection{Linear Regression (\texorpdfstring{$f: \mathbb{R}^D \to \mathbb{R}$}{R -> R})}
For a continuous target we use the identity activation, so the prediction is simply the linear score:
\[ \hat{y} = z = Wx + b. \]
The model is trained by minimizing the \textbf{Mean Squared Error (MSE)}:
\[ L = \frac{1}{N} \sum_{i=1}^N {(y_i - \hat{y}_i)}^2. \]

\subsection{Logistic Regression (\texorpdfstring{$f: \mathbb{R}^D \to [0, 1]$}{R -> [0, 1]})}
For binary classification we squash the score into $[0,1]$ with the \textbf{Sigmoid} function:
\[ P(Y=1 | X=x) = \sigma(z) = \frac{1}{1 + e^{-z}}. \]
The corresponding loss is the \textbf{Binary Cross-Entropy (BCE)}:
\[ L = -\frac{1}{N} \sum_{i=1}^N \left[ y_i \log(\sigma(z_i)) + (1 - y_i) \log(1 - \sigma(z_i)) \right]. \]
The two terms cover the two possible labels: when $y_i=1$ only the first one is active, and when $y_i=0$ only the second one is. In this way the loss penalizes the model whenever it assigns a low probability to the correct class.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.7\textwidth]{Pictures/logistic.png}
    \caption{The Sigmoid function used in Logistic Regression.}\label{fig:logisticregresssion}
\end{figure}

\subsection{Softmax Classifier (\texorpdfstring{$f: \mathbb{R}^D \to \{0, \dots, K\}$}{R -> \{0, \dots, K\}})}
The Softmax Classifier generalizes Logistic Regression to $K$ mutually exclusive classes. It maps the raw scores into a valid probability distribution:
\[ P(Y = k | X = x_i) = \frac{e^{z_k}}{\sum_j e^{z_j}}. \]
The Softmax function makes all scores positive and normalizes them so that they sum to one, which is exactly what we need to interpret them as probabilities.

\begin{examplebox}
For an input image of size $32 \times 32 \times 3$ (e.g., CIFAR-10), the flattened array $x$ has $3072$ numbers. If we are classifying into 10 categories, the weight matrix $W$ has dimensions $10 \times 3072$, producing a vector of $10$ raw class scores before the Softmax is applied.
\end{examplebox}

We train the model with the \textbf{cross-entropy loss}, i.e.\ the negative log-probability of the correct class:
\[ L_i = -\log P(Y = y_i | X = x_i). \]
This is the loss shown in the lecture slides. Minimizing it pushes the score of the correct class up and the scores of the other classes down, so that the correct class becomes increasingly likely.

\begin{figure}[htbp]

    \caption{The Softmax function converts raw class scores into a probability distribution.}\label{fig:Softmax}
\end{figure}

\section{Deep Feedforward Networks and Backpropagation}

\subsection{Deep Neural Networks}
By stacking linear layers and non-linear activation functions we obtain a multi-layer Neural Network (MLP):
\[ f = W_2 \max(0, W_1 x + b_1) + b_2. \]
This is the two-layer network shown in the lecture slides. The non-linearity is essential: without it, the two matrices would collapse into a single linear transformation.

\subsection{Backpropagation}
To train the network we need the gradient of the loss with respect to every parameter. \textbf{Backpropagation}~\cite{rumelhart1986learning} does this by applying the chain rule backwards, from the output to the input.

\begin{Notebox}
\textbf{Backpropagation with Matrices:} When inputs and weights are vectors or matrices, the local gradients are Jacobian matrices. In practice frameworks never form them explicitly; they compute the resulting vector--Jacobian products directly. A useful check is that the gradient $\partial L/\partial x$ always has the same shape as $x$.
\end{Notebox}

\section{The Role of Activation Functions}

An \textbf{activation function} is applied to the affine output of a layer ($z = Wx+b$) before it is passed on. Its job is to introduce \textbf{non-linearity} into the network.

\begin{Notebox}
\textbf{Why do we need non-linearity?} A two-layer linear network computes $W_2(W_1 x) = (W_2 W_1)x$, which is still a linear function. Non-linear activations allow the network to approximate complex, non-linear decision boundaries.
\end{Notebox}

Some of the most common activation functions are shown in Figure~\ref{fig:ActivationFunction}.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.7\textwidth]{Pictures/Activation_fun.png}
    \caption{Illustration of common activation functions.}\label{fig:ActivationFunction}
\end{figure}

\subsection{ReLU (Rectified Linear Unit)}
\textbf{Formula:} $f(x) = \max(0, x)$. ReLU is the classic default: it does not saturate for positive inputs, it is cheap to compute, and in practice it converges much faster than Sigmoid or Tanh (often about $6\times$ faster). Its main weakness is the \textbf{``Dead ReLU''} problem: for $x<0$ the gradient is exactly zero, so a neuron can get stuck and stop updating.

\subsection{Leaky ReLU}
\textbf{Formula:} $f(x) = \max(\alpha x, x)$, with $\alpha \approx 0.01$. Introduced by Maas et al.~\cite{maas2013rectifier}, it keeps the advantages of ReLU but gives a small non-zero slope for negative inputs, so neurons do not die permanently.

\subsection{ELU (Exponential Linear Units)}
\textbf{Formula:} $f(x) = x$ if $x > 0$, otherwise $\alpha(e^x - 1)$. Proposed by Clevert et al.~\cite{clevert2015fast}, ELU keeps the benefits of ReLU and brings the mean activation closer to zero. Its negative saturation regime adds some robustness to noise, but evaluating the exponential is more expensive than a simple comparison.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.4\textwidth]{Pictures/Elu.png}
    \caption{Illustration of ELU.}\label{fig:Elu}
\end{figure}

\subsection{GELU (Gaussian Error Linear Unit)}
\textbf{Formula:} $f(x) = x \cdot \Phi(x)$, where $\Phi(x)$ is the cumulative distribution function (CDF) of the standard normal distribution. Introduced by Hendrycks and Gimpel~\cite{hendrycks2016gaussian}, GELU behaves smoothly around zero, which facilitates optimization. It is used in GPT, BERT and many modern Vision Transformers; the price is a slightly higher computational cost than ReLU.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.4\textwidth]{Pictures/Gelu.png}
    \caption{Illustration of GELU.}\label{fig:gelu}
\end{figure}

Two historical activations are worth mentioning. \textbf{Sigmoid} and \textbf{Tanh} were common in early networks, but both saturate and therefore slow down learning in deep stacks. \textbf{Maxout} is a less common variant that takes the maximum over several learned linear projections. In modern vision and language models, ReLU and GELU are the standard choices.

\begin{Notebox}
\textbf{In practice:} use ReLU as the default, be careful with the learning rate to avoid dead neurons, and try Leaky ReLU or GELU if you want a small improvement. Avoid Sigmoid or Tanh in the hidden layers of deep networks; they are still useful as output gates or inside recurrent cells.
\end{Notebox}

\section{Weight Initialization and Signal Propagation}

Proper initialization is crucial: with a bad starting point, training can fail before it begins, either because the signal collapses or because it explodes.

\subsection{The Pitfalls of Naive Initialization}
\begin{itemize}[nosep, leftmargin=*]
    \item \textbf{Constant initialization ($W = \text{constant}$):} if all weights start with the same value, all neurons in a layer produce identical outputs and receive identical gradients. The network cannot break symmetry and cannot learn different features.
\end{itemize}

\subsubsection*{Small Random Noise and Vanishing Gradients}
A common naive choice is to initialize the weights with small random values, such as \texttt{W = 0.01 * }\allowbreak\texttt{np.random.randn(D, H)}. This seems harmless, but in a deep network it makes the signal die layer by layer.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=1\textwidth]{Pictures/activation_stats.png}
    \caption{Distribution of activations $x$ across 6 layers with $W \sim \mathcal{N}(0, 0.01)$ and Tanh.}\label{fig:activation_stats}
\end{figure}

Figure~\ref{fig:activation_stats} shows the distribution of the activations across six layers. Because the weights are scaled by $0.01$, the variance shrinks at every layer; by layer 6 the activations have collapsed to zero (standard deviation $0.05$).

The same phenomenon appears in the backward pass. The gradient of a weight is proportional to the input activation, so when the activations are close to zero, the weight gradients are also close to zero. The network is still running, but it is no longer learning.

\subsection{Variance Scaling Methods: The Solution}
To keep the signal variance stable, we scale the initial weights according to the fan-in $D_{in}$ of each neuron.

\begin{keywordbox}
\textbf{1. Xavier (Glorot) Initialization}\\
Designed for symmetric, zero-centered activations such as Tanh or Sigmoid. The weights are drawn with standard deviation
\[ \text{std} = \frac{1}{\sqrt{D_{in}}}. \]

\textbf{2. Kaiming (He) Initialization (He et al., 2015)~\cite{he2015delving}}\\
ReLU zeroes out the negative half of the inputs, which roughly halves the variance at every layer. Kaiming initialization compensates by doubling the variance:
\[ \text{std} = \sqrt{\frac{2}{D_{in}}}. \]
This is the standard choice for deep ReLU networks. For convolutional layers, $D_{in}$ is the kernel size squared times the number of input channels.
\end{keywordbox}

\section{Gradient-Based Optimization Algorithms}

The objective is the average loss over the training set, plus the regularization term:
\[ L(W) = \frac{1}{N} \sum_{i=1}^N L_i(x_i, y_i, W) + \lambda R(W). \]
The exact gradient therefore requires a full pass over all $N$ examples:
\[ \nabla_W L(W) = \frac{1}{N} \sum_{i=1}^N \nabla_W L_i(x_i, y_i, W) + \lambda \nabla_W R(W). \]
For large datasets this is too expensive. \textbf{Stochastic Gradient Descent (SGD)} approximates the gradient with a small random \textbf{minibatch} (32, 64 or 128 examples are common), so we can perform many cheap updates instead of a few expensive ones.

\begin{keywordbox}
\textbf{Stochastic Gradient Descent (SGD):} instead of the full sum, SGD estimates the gradient on a small minibatch. The estimate is noisy, but the updates are much more frequent and the network converges faster in practice.
\end{keywordbox}

\section{Regularization in Deep Neural Networks}

The goal of \textbf{regularization} is to prevent overfitting by controlling the capacity of the model. We add a penalty $R(W)$ to the empirical loss:
\[ L_{total}(W, X) = \underbrace{L(W, X)}_{\text{data loss}} + \underbrace{\lambda R(W)}_{\text{regularization}}. \]
The hyperparameter $\lambda$ sets the strength of the penalty: with $\lambda=0$ the model only fits the training data and can overfit; as $\lambda \to \infty$ the penalty dominates and the model underfits.

The classical penalties are:
\begin{itemize}[nosep, leftmargin=*]
    \item \textbf{L2 (weight decay):} $R(W) = \sum W^2$. It discourages large weights and spreads the representation across many neurons.
    \item \textbf{L1 (Lasso):} $R(W) = \sum |W|$. It pushes less useful weights exactly to zero and performs feature selection.
\end{itemize}

Elastic net combines L1 and L2. Stochastic depth and fractional pooling are architectural variants: instead of adding a penalty to the loss, they inject randomness into the structure of the network during training.

\subsection{Dropout}

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.7\textwidth]{Pictures/dropout.png}
    \caption{Illustration of Dropout during training.}\label{fig:dropout}
\end{figure}

Introduced by Srivastava et al.~\cite{srivastava2014dropout}, \textbf{Dropout} randomly deactivates individual neurons during training with probability $p$ (commonly $p=0.5$). This prevents neurons from relying on the specific activations of their neighbors and forces them to learn robust, self-reliant features. It also has an ensemble interpretation: dropout implicitly trains an exponential number of shared-weight subnetworks ($2^N$ for a layer with $N$ neurons).

\subsubsection{Inverted Dropout}
Because dropping neurons reduces the active sum of signals, the expected output at test time (when all neurons are active) would be scaled by $\frac{1}{1-p}$. Modern implementations avoid any scaling at inference time by using \textbf{Inverted Dropout} during training:
\[ h_{\text{train}} = \frac{\text{mask} \odot x}{1-p}. \]
The numerator drops a random fraction $p$ of the activations, while the denominator inflates the surviving ones so that their expected value matches the deterministic value at test time ($h_{\text{test}} = x$).

\begin{examplebox}
\textbf{Numerical example ($p=0.5$):} for $x = [10, 20, 30, 40]$ and mask $[1, 0, 1, 0]$, the masked output is $[10, 0, 30, 0]$. Dividing by $1-p=0.5$ gives $[20, 0, 60, 0]$, so the expected sum is preserved.
\end{examplebox}

\subsection{The Common Pattern of Modern Regularization}
Dropout illustrates a pattern that appears in many modern regularizers: during training we inject randomness, and at test time we average it out (or approximate the average). Batch normalization is another example: it uses random minibatch statistics during training and fixed running statistics at test time.

\section{Feature Normalization Techniques}

To stabilize the signal and speed up optimization, we normalize the activations inside the network.

\subsection{Batch Normalization}
Introduced by Ioffe and Szegedy~\cite{ioffe2015batch}, Batch Normalization (BN) normalizes each feature channel $k$ across the minibatch:
\[ \widehat{x}^{(k)} = \frac{x^{(k)} - \text{E}[x^{(k)}]}{\sqrt{\text{Var}[x^{(k)}] + \epsilon}}, \]
where the mean and variance are computed over the current minibatch and $\epsilon$ avoids division by zero.

To avoid making the normalization too rigid, BN adds two learnable parameters:
\[ y^{(k)} = \gamma^{(k)} \widehat{x}^{(k)} + \beta^{(k)}. \]
If the network needs the original activations, it can learn $\gamma^{(k)} = \sqrt{\text{Var}[x^{(k)}]}$ and $\beta^{(k)} = \text{E}[x^{(k)}]$, which recovers the identity (up to the small $\epsilon$).

During training the statistics come from the current minibatch. At inference time we use running averages collected during training, so BN becomes a fixed linear operation and can be fused into the preceding layer.

\subsection{Alternative Normalization Methods}

\begin{figure}[htbp]
    \centering
    \includegraphics[width=1\textwidth]{Pictures/normalization_methods.png}
    \caption{Comparison of different normalization methods across batch ($N$), channel ($C$), and spatial ($H, W$) dimensions.}\label{fig:normalization_methods}
\end{figure}

The normalization methods differ in the axes over which they aggregate statistics (Figure~\ref{fig:normalization_methods}):
\begin{itemize}[nosep, leftmargin=*]
    \item \textbf{Batch Norm (BN):} across the batch and spatial dimensions, independently for each channel~\cite{ioffe2015batch}. It works well for vision models with large minibatches.
    \item \textbf{Layer Norm (LN):} across all channels and spatial dimensions for each sample~\cite{ba2016layer}. It does not depend on the batch size, which makes it the standard choice for RNNs and Transformers.
    \item \textbf{Instance Norm (IN):} across the spatial dimensions for each channel of each sample~\cite{ulyanov2016instance}. It is widely used in style transfer.
    \item \textbf{Group Norm (GN):} across groups of channels for each sample~\cite{wu2018group}. It is batch-size independent while still allowing channel specialization.
\end{itemize}

\section{Practical Training Recipe}

The concepts above explain why a network can learn; this short section collects the practical steps that make training work in practice.

\subsection{Data Preprocessing}
Before training, we center and normalize the inputs. For images, a common choice is to subtract the per-channel mean; some models also divide by the per-channel standard deviation. This makes the loss less sensitive to small changes in the weights and speeds up optimization. For CIFAR-10, for example, we subtract the mean image or the per-channel mean from every image.

\subsection{Early Stopping}
We monitor the validation loss during training. When it stops improving, we stop training and keep the checkpoint with the best validation accuracy. Early stopping is a simple and effective regularizer: it prevents the model from continuing to fit the training set after it has started to overfit.

\subsection{Choosing Hyperparameters}
A practical recipe is:
\begin{enumerate}[leftmargin=*]
    \item check the initial loss (it should be reasonable, not NaN or enormous);
    \item overfit a small subset of the data (the training accuracy should approach 100\%);
    \item search a coarse grid of learning rates and weight decay values;
    \item refine the grid around the best values and train longer.
\end{enumerate}
This is much cheaper than tuning many hyperparameters at once.
