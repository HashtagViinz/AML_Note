\section{Parametric Models and Optimization Foundations}

The majority of machine learning models can be formulated as \textbf{Parametric Models}. A parametric model takes an input $x$ and uses a set of parameters (or weights) $W$ and biases $b$ to produce an output prediction $z$:
\[ z = f(x,W) = Wx + b \]

While the exact nature of the prediction depends on the task, what unifies these models is the \textbf{Optimization Process}. We define a Loss function $L$ that measures the error of our predictions, and we iteratively adjust the weights using \textbf{Gradient Descent}:
\[ W^{t+1} = W^t - \alpha \nabla_W L \]
where $\alpha$ is the learning rate.

By simply changing the \textit{activation function} applied to the linear score $z$ and the corresponding \textit{loss function}, we obtain different classical models: Linear Regression, Logistic Regression, and the Softmax Classifier.

\subsection{Linear Regression (\texorpdfstring{$f: \mathbb{R}^D \to \mathbb{R}$}{R -> R})}
Linear Regression is used when the target variable is continuous. We use the identity activation function (i.e., no activation), so the predicted output $\hat{y}$ is exactly the linear score:
\[ \hat{y} = z = Wx + b \]
We optimize this model by minimizing the \textbf{Mean Squared Error (MSE)} loss:
\[ L = \frac{1}{N} \sum_{i=1}^N {(y_i - \hat{y}_i)}^2 \]

\subsection{Logistic Regression (\texorpdfstring{$f: \mathbb{R}^D \to [0, 1]$}{R -> [0, 1]})}
Logistic Regression is used for binary classification. We map the linear score $z$ to a probability between 0 and 1 using the \textbf{Sigmoid} activation function $\sigma(z)$:
\[ P(Y=1 | X=x) = \sigma(z) = \frac{1}{1 + e^{-z}} \]
The appropriate loss function for this model is the \textbf{Binary Cross-Entropy Loss (BCE)}. For a dataset of $N$ samples, it is defined as:
\[ L = -\frac{1}{N} \sum_{i=1}^N \left[ \underbrace{y_i \log(\sigma(z_i))}_{\text{Active if } y=1} + \underbrace{(1 - y_i) \log(1 - \sigma(z_i))}_{\text{Active if } y=0} \right] \]

\begin{Notebox}
\textbf{Understanding the BCE Formula:} This equation uses a clever mathematical trick to combine two mutually exclusive cases into a single line:
\begin{itemize}[nosep, leftmargin=*]
    \item When the true class is \textbf{$y_i = 1$}, the second term $(1 - 1) = 0$ disappears, and the loss evaluates only $-\log(\sigma(z_i))$, penalizing the model if it predicts a low probability.
    \item When the true class is \textbf{$y_i = 0$}, the first term $0$ disappears, and the loss evaluates only $-\log(1 - \sigma(z_i))$, penalizing the model if it predicts a high probability for class 1.
\end{itemize}
\end{Notebox}

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.7\textwidth]{Pictures/logistic.png}
    \caption{Illustration of the Sigmoid function in Logistic Regression.}\label{fig:logisticregresssion}
\end{figure}

\subsection{Softmax Classifier (\texorpdfstring{$f: \mathbb{R}^D \to \{0, \dots, K\}$}{R -> \{0, \dots, K\}})}
The Softmax Classifier generalizes Logistic Regression to multiple, mutually exclusive classes. It maps the raw scores $z$ into a valid probability distribution over the classes using the \textbf{Softmax function}:
\[ P(Y = k | X = x_i) = \frac{e^{z_k}}{\sum_j e^{z_j}} \]

\begin{Notebox}
\textbf{Why Softmax?} We want to interpret raw classifier scores as \textit{probabilities}. The Softmax function transforms scores such that they are strictly positive and sum to 1.
\end{Notebox}

\begin{examplebox}
For an input image of size $32 \times 32 \times 3$ (e.g., CIFAR-10), the flattened array $x$ has $3072$ numbers. If we are classifying into 10 categories, the weight matrix $W$ will have dimensions $10 \times 3072$, producing a $10 \times 1$ vector of raw class scores before the Softmax is applied.
\end{examplebox}

We then optimize the model using the \textbf{Categorical Cross-Entropy Loss}, often referred to as the Negative Log-Likelihood (NLL). Over the entire dataset of $N$ samples, expanding the Softmax probability formula, the loss becomes:
\[ NLL(W, X) = -\sum_{i=1}^N \left[ \underbrace{W_{y_i}^T x_i}_{\text{Punteggio della classe giusta}} - \underbrace{\log \left( \sum_{k=1}^K \exp(W_k^T x_i) \right)}_{\text{Somma dei punteggi delle altre classi}} \right] \]

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.7\textwidth]{Pictures/softmax.png}
    \caption{Abstract representation of logistic regression.}\label{fig:Softmax}
\end{figure}

\begin{Notebox}
\textbf{Understanding the Softmax NLL Formula:} 
By looking at the expanded formula, we see that the optimizer tries to maximize the linear score $W_{y_i}^T x_i$ of the \textit{correct class} $y_i$, while simultaneously pushing down the log-sum of the scores of \textit{all available classes}. This creates a competitive environment where increasing the score of the correct class implicitly decreases the relative probability of the others.
\end{Notebox}

\section{Deep Feedforward Networks and Backpropagation}

\subsection{Deep Neural Networks}
By stacking multiple layers and applying non-linear activation functions, we construct multi-layer Neural Networks (Multi-Layer Perceptrons, MLPs):
\[ f = W_2 \max(0, W_1 x + b_1) + b_2 \]
This hierarchical representation enables the network to learn rich, non-linear representations from raw data.

\subsection{Backpropagation}
To train a deep network, we compute the gradient of the loss with respect to all parameters using the \textbf{Backpropagation} algorithm, which systematically applies the multivariable chain rule from the output back to the inputs (backward pass).

\begin{Notebox}
\textbf{Backpropagation with Matrices:} When inputs and weights are vectors or matrices, local gradients become \textit{Jacobian matrices}. However, Jacobians are often sparse. Instead of explicitly forming them, practical frameworks use implicit vector-Jacobian products. A crucial dimensional consistency check to remember: the downstream gradient $\frac{\partial L}{\partial x}$ \textbf{always has the exact same shape} as the tensor $x$!
\end{Notebox}

\section{The Role of Activation Functions}

An \textbf{activation function} is a mathematical operator applied to the affine output of a layer ($z = Wx+b$) before passing it to subsequent layers. Its primary role is to introduce \textbf{non-linearity} into the network. 

\begin{Notebox}
\textbf{Why do we need Non-Linearity?} If we only stacked linear layers without activation functions, the entire deep network would mathematically collapse into a single linear transformation. For example, a 2-layer linear network $f = W_2(W_1 x)$ can be rewritten as $f = W'x$ where $W' = W_2 W_1$. Non-linear activations allow the network to approximate arbitrarily complex, non-linear decision boundaries.
\end{Notebox}

Some of the most widely used activation functions are illustrated in Figure~\ref{fig:ActivationFunction}:

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.7\textwidth]{Pictures/Activation_fun.png}
    \caption{Illustration of common activation functions.}\label{fig:ActivationFunction}
\end{figure}

\subsection{ReLU (Rectified Linear Unit)}
\textbf{Formula:} $f(x) = \max(0, x)$ \\
ReLU is the classic default activation function across deep learning architectures.
\begin{itemize}[nosep, leftmargin=*]
    \item \textbf{Pros:} It does not saturate in the positive region. It is highly computationally efficient (just a thresholding operation) and converges significantly faster than Sigmoid or Tanh in practice (often roughly $6\times$ faster).
    \item \textbf{Cons:} Its outputs are not zero-centered. Most importantly, it suffers from the \textbf{``Dead ReLU''} problem: if an activation falls into the negative regime ($x < 0$), its local gradient is exactly $0$. If a neuron is pushed into this regime by an unfortunate large weight update, it will never update its weights again.
\end{itemize}

\subsection{Leaky ReLU}
\textbf{Formula:} $f(x) = \max(\alpha x, x)$ (where typically $\alpha = 0.01$) \\
Designed specifically to prevent the ``dead neuron'' problem of standard ReLU\@.
\begin{itemize}[nosep, leftmargin=*]
    \item \textbf{Pros:} Retains all the computational advantages of ReLU (no positive saturation, fast evaluation), while the small non-zero slope for negative inputs guarantees that neurons will never permanently die.
\end{itemize}

\subsection{ELU (Exponential Linear Units)}
\textbf{Formula:} $f(x) = x$ if $x > 0$, else $\alpha(e^x - 1)$
\begin{itemize}[nosep, leftmargin=*]
    \item \textbf{Pros:} Inherits the benefits of ReLU, but produces outputs with a mean closer to zero. Its smooth negative saturation regime adds noise robustness compared to unbounded negative regimes.
    \item \textbf{Cons:} More computationally demanding because evaluating the exponential function $e^x$ is slower than simple comparisons.
\end{itemize}

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.4\textwidth]{Pictures/Elu.png}
    \caption{Illustration of ELU.}\label{fig:Elu}
\end{figure}

\subsection{GELU (Gaussian Error Linear Unit)}
\textbf{Formula:} $f(x) = x \cdot \Phi(x)$, where $\Phi(x)$ is the cumulative distribution function (CDF) of the standard normal distribution.
\begin{itemize}[nosep, leftmargin=*]
    \item \textbf{Pros:} Exhibits smooth probabilistic gating behavior around $0$. Its continuous curvature facilitates optimization in state-of-the-art architectures, making it the standard choice in \textbf{GPT, BERT}, and modern Vision Transformers.
    \item \textbf{Cons:} Slightly higher computational cost than ReLU\@.
\end{itemize}

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.4\textwidth]{Pictures/Gelu.png}
    \caption{Illustration of GELU.}\label{fig:gelu}
\end{figure}

\begin{Notebox}
\textbf{TL;DR --- Practical Guidelines for Activation Functions:}
\begin{itemize}[nosep, leftmargin=*]
    \item Use \textbf{ReLU} as your standard baseline, monitoring learning rates to avoid dead neurons.
    \item Explore \textbf{Leaky ReLU} or \textbf{GELU} for improved gradient flow and smoother optimization.
    \item Avoid \textbf{Sigmoid/Tanh} for intermediate hidden layers of deep networks, reserving them strictly for output gates or bounded representations (such as in LSTM cells).
\end{itemize}
\end{Notebox}

\section{Weight Initialization and Signal Propagation}

Properly initializing the weights of a neural network is crucial. With poor initialization, training can fail entirely before it starts due to signal collapse or numerical explosion.

\subsection{The Pitfalls of Naive Initialization}
\begin{itemize}[nosep, leftmargin=*]
    \item \textbf{Constant Initialization ($W = \text{constant}$):} If all weights are initialized to the same value (e.g., $W=0$), all neurons in a given layer will produce identical outputs and receive identical gradients during backpropagation. The network fails to \textit{break symmetry} and cannot learn independent features.
\end{itemize}

\subsubsection*{Small Random Noise and Vanishing Gradients}
A common naive approach is initializing weights with small random numbers, such as \texttt{W = 0.01 * }\allowbreak\texttt{np.random.randn(D, H)}, where weights are sampled from a standard normal distribution scaled by a tiny standard deviation of $0.01$. % chktex 36

In deep networks, this naive scaling causes complete signal extinction:

\begin{figure}[htbp]
    \centering
    \includegraphics[width=1\textwidth]{Pictures/activation_stats.png}
    \caption{Distribution of activations $x$ across 6 layers with $W \sim \mathcal{N}(0, 0.01)$ and Tanh.}\label{fig:activation_stats}
\end{figure}

\begin{itemize}[leftmargin=*]
    \item \textbf{Step 1: The Forward Pass (Shrinking Activations).}\\
    The histograms in Figure~\ref{fig:activation_stats} illustrate the distribution of \textbf{activations} across successive layers. Because the weights are scaled by $0.01$, the output of each layer is strictly smaller in variance than its input. Across sequential layers, this repeated multiplication causes the signal energy to exponentially decay. By Layer 6, activations have completely collapsed to $0$ ($\text{std} = 0.05$).
    
    \item \textbf{Step 2: The Backward Pass (Vanishing Gradients).}\\
    During backpropagation through a linear layer $y = Wx$, the local gradient with respect to weights is $\frac{\partial y}{\partial W} = x$. Therefore, the gradient of the Loss with respect to $W$ is:
    \[ \frac{\partial L}{\partial W} = x^T \frac{\partial L}{\partial y} \]
    \textbf{The weight update is directly proportional to the magnitude of the input activations $x$}. Because the forward pass collapsed the activations to $0$, the weight gradient evaluates to $\frac{\partial L}{\partial W} \approx 0 \cdot \frac{\partial L}{\partial y} = 0$, bringing learning to a complete standstill.
\end{itemize}

\subsection{Variance Scaling Methods: The Solution}
To guarantee that signal variance remains stable across deep layers, we scale initial weights \textbf{dynamically} based on the fan-in ($D_{in}$) of each neuron:

\begin{keywordbox}
\textbf{1. Xavier (Glorot) Initialization}\\
Designed for symmetric, zero-centered activation functions like \textbf{Tanh} or \textbf{Sigmoid}. The variance of activations is kept constant across layers by drawing weights from a distribution with standard deviation:
\[ \text{std} = \frac{1}{\sqrt{D_{in}}} \]

\textbf{2. Kaiming (He) Initialization}\\
Xavier initialization fails with \textbf{ReLU} because ReLU zeroes out all negative values, effectively halving the variance at each step. Kaiming initialization compensates by doubling the variance, setting the standard deviation to:
\[ \text{std} = \sqrt{\frac{2}{D_{in}}} \]
This is the standard and mandatory initialization when training deep ReLU networks.
\end{keywordbox}

\section{Gradient-Based Optimization Algorithms}

From a theoretical standpoint, our objective is to minimize the total loss over the entire dataset:
\[ L(W) = \frac{1}{N} \sum_{i=1}^N L_i(x_i, y_i, W) + \lambda R(W) \]
The exact gradient requires summing over all $N$ training examples:
\[ \nabla_W L(W) = \frac{1}{N} \sum_{i=1}^N \nabla_W L_i(x_i, y_i, W) + \lambda \nabla_W R(W) \]

Computing this \textbf{Full Batch} gradient requires evaluating millions of samples at every parameter update, which is computationally prohibitive.

\begin{keywordbox}
\textbf{Stochastic Gradient Descent (SGD):} Instead of the full sum, SGD approximates the true gradient over a small random \textbf{minibatch} of examples (e.g., 32, 64, or 128). While this introduces stochastic variance, it allows frequent, computationally cheap updates that accelerate convergence.
\end{keywordbox}

\section{Regularization in Deep Neural Networks}

The objective of \textbf{Regularization} is to prevent models from overfitting training data by controlling model capacity. We add a parameter complexity penalty $R(W)$ to the empirical loss:
\[ L_{total}(W, X) = \underbrace{L(W, X)}_{\text{Data Loss}} + \underbrace{\lambda R(W)}_{\text{Regularization Term}} \]

\begin{Notebox}
\textbf{Role of the Hyperparameter $\lambda$:}
\begin{itemize}[nosep, leftmargin=*]
    \item $\lambda = 0$: The model focuses solely on fitting training data, risking \textbf{Overfitting}.
    \item $\lambda \to \infty$: The penalty dominates, forcing all weights toward zero and causing \textbf{Underfitting}.
\end{itemize}
\end{Notebox}

Classic mathematical penalties include:
\begin{itemize}[nosep, leftmargin=*]
    \item \textbf{L2 Regularization (Weight Decay / Ridge):} $R(W) = \sum W^2$. Penalizes large weights quadratically, encouraging diffuse representations across all neurons.
    \item \textbf{L1 Regularization (Lasso):} $R(W) = \sum |W|$. Drives less relevant weights exactly to zero, performing automatic feature selection.
\end{itemize}

\subsection{Dropout}

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.7\textwidth]{Pictures/dropout.png}
    \caption{Illustration of Dropout during training.}\label{fig:dropout}
\end{figure}

Introduced by Srivastava et al. (2014), \textbf{Dropout} is a stochastic regularization technique where individual neurons are randomly deactivated during training with probability $p$ (commonly $p=0.5$).
\begin{itemize}[nosep, leftmargin=*]
    \item \textbf{Prevents Co-adaptation:} Neurons cannot rely on the specific activations of neighboring units, forcing them to learn robust, self-reliant features.
    \item \textbf{Ensemble Effect:} Dropout implicitly trains an exponential ensemble of shared-weight subnetworks ($2^N$ sub-architectures for an $N$-neuron layer).
\end{itemize}

\subsubsection{Inverted Dropout}
Because dropping neurons during training reduces the active sum of signals, the expected output at test time (when all neurons are active) would be scaled by $\frac{1}{1-p}$. To eliminate any scaling overhead at inference time, modern implementations use \textbf{Inverted Dropout} during training:
\[ h_{\text{train}} = \frac{\text{mask} \odot x}{1-p} \]

\begin{itemize}[leftmargin=*]
    \item \textbf{Numerator ($\text{mask} \odot x$):} Drops a random fraction $p$ of the activations to zero.
    \item \textbf{Denominator ($1-p$):} Inflates the surviving activations, ensuring that the expected activation value during training matches the deterministic magnitude at test time ($h_{\text{test}} = x$).
\end{itemize}

\begin{examplebox}
\textbf{Numerical Example of Inverted Dropout ($p=0.5$):} \\
Given input $x = [10, 20, 30, 40]$ (Sum $= 100$) and mask $[1, 0, 1, 0]$:
\[ \text{Masked output: } [10, 0, 30, 0] \quad (\text{Sum drops to } 40) \]
\[ h_{\text{train}} = \frac{[10, 0, 30, 0]}{0.5} = [20, 0, 60, 0] \quad (\text{Scaled sum } = 80 \approx 100) \]
\end{examplebox}

\subsection{The Common Pattern of Modern Regularization}
Dropout illustrates the universal recipe of modern deep learning regularization:
\begin{enumerate}
    \item \textbf{Training:} Inject stochasticity or random noise.
    \item \textbf{Testing:} Marginalize or average out the randomness to yield deterministic predictions.
\end{enumerate}

\section{Feature Normalization Techniques}

To stabilize signal distributions and accelerate optimization in deep networks, activations are explicitly normalized across intermediate layers.

\subsection{Batch Normalization}
Batch Normalization (BN) normalizes activations across the minibatch dimension, forcing each feature channel $k$ to zero mean and unit variance:
\[ \widehat{x}^{(k)} = \frac{x^{(k)} - \text{E}[x^{(k)}]}{\sqrt{\text{Var}[x^{(k)}] + \epsilon}} \]
where $\text{E}[x^{(k)}]$ and $\text{Var}[x^{(k)}]$ are the minibatch mean and variance, and $\epsilon$ prevents division by zero.

\subsubsection{Learnable Scale and Shift Parameters}
To prevent rigid normalization from limiting network capacity, two learnable parameters ($\gamma$ and $\beta$) restore representational flexibility:
\[ y^{(k)} = \gamma^{(k)} \widehat{x}^{(k)} + \beta^{(k)} \]
If beneficial, the optimizer can recover the identity mapping by setting $\gamma^{(k)} = \sqrt{\text{Var}[x^{(k)}]}$ and $\beta^{(k)} = \text{E}[x^{(k)}]$.

\subsubsection{Training versus Test Phase}
During training, statistics are calculated over the current minibatch. During inference, fixed global running averages computed during training are used, allowing BN to be mathematically folded into preceding linear layers with zero inference overhead.

\subsection{Alternative Normalization Methods}

\begin{figure}[htbp]
    \centering
    \includegraphics[width=1\textwidth]{Pictures/normalization_methods.png}
    \caption{Comparison of different normalization methods across batch ($N$), channel ($C$), and spatial ($H, W$) dimensions.}\label{fig:normalization_methods}
\end{figure}

The choice among normalization methods depends on the axes across which statistics are aggregated (Figure~\ref{fig:normalization_methods}):

\subsubsection{Batch Norm (BN)}
Aggregates across the batch dimension $N$ and spatial dimensions $(H, W)$ independently for each channel $C$. Ideal for vision models with large minibatches.

\subsubsection{Layer Norm (LN)}
Aggregates across all channels $C$ and spatial dimensions for each individual sample $N$. Independent of batch size, making it the standard for RNNs and Transformers.

\subsubsection{Instance Norm (IN)}
Aggregates strictly across spatial dimensions $(H, W)$ for each single channel of each single sample. Widely used in generative style transfer.

\subsubsection{Group Norm (GN)}
Divides the channel dimension $C$ into distinct groups and aggregates across each group per sample. Provides batch-size independence while preserving channel specialization.

\textbf{The Logical Connections Between Nodes:}
\begin{itemize}[leftmargin=*]
    \item \textbf{From Node 1 to 2:} A single linear layer cannot approximate complex non-linear functions; we must stack layers into deep networks, which in turn requires Backpropagation to compute parameter gradients.

    \item \textbf{From Node 6 to 7:} Throughout deep optimization, intermediate layer distributions continuously drift; Batch, Layer, and Group Normalization re-center activations to maintain high learning rates and stable convergence.
\end{itemize}
\end{InsightBox}
